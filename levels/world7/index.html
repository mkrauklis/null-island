Your code

openDirections() never tells you which way is right — only which ways are open. The cave itself has exactly one route from start to exit (no loops to worry about), so "every direction except the one I just came from" is always a safe rule to explore by. Check atGoal() before you go further — a search that keeps exploring after it's already found the exit will run out of moves on a big enough cave.
