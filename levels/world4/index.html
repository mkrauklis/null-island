A function is just a named block of moves — define it once with function name() { ... }, then call name(); anywhere you'd otherwise retype the same lines.
Red Light, Green Light: the squid's eye cycles on a fixed pattern — grey and looking around, then red and watching. Any move you make while it's red gets you caught, no matter where you are on the catwalk. wait() is always safe.
