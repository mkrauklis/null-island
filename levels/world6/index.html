Area 6 — The Core

The source of the island's corruption: a mutated thing with five tentacles, each one strapped with a bomb. You can't watch all five at once — you have to tell the terminal what to do the instant each one opens up, then get out of the way and let it happen.

Your code

Register a handler for every tentacle first, then run out the clock with wait() (a loop makes this short) until every bomb has gone off. Only once all five are destroyed does walking to the end actually count.
